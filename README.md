# PC16 Week 14 – Instagram-Inspired Static UI

This project contains two static Flutter screens:
- Home Page (`HomeScreen`)
- Profile Page (`ProfileScreen`)

## Requirements
- Flutter SDK
- VS Code or Android Studio
- Android emulator or physical Android device

## Setup
1. Open this folder in VS Code.
2. In the terminal, run `flutter pub get`.
3. Run `flutter run`.

## Preview the Home Page
In `lib/main.dart`, set:
`home: const HomeScreen(),`

## Preview the Profile Page
Temporarily change that line to:
`home: const ProfileScreen(),`

Run the app again. This is only a preview configuration; no navigation is implemented.

## Assets
Local images are stored in `assets/images/` and registered in `pubspec.yaml`.

## Notes
The icons and button-like elements are static visual representations. They do not perform actions.
